# Introduction to UML Modeling

## Description
This project introduces the fundamentals of Unified Modeling Language (UML) as a core tool for software design and architecture. It covers structural and behavioral modeling using Mermaid syntax, focusing on extracting system requirements, defining classes with Python-compliant data types, and modeling class relationships and interactions.

## Learning Objectives
- Extract classes, attributes, and methods from system descriptions.
- Model object-oriented relationships (Association, Aggregation, Composition, Generalization).
- Determine multiplicity based on domain constraints.
- Represent system structures using UML Class Diagrams.
- Model behavioral interactions using UML Sequence Diagrams.
- Write valid diagrams using Mermaid syntax.

## Requirements
- Files written in Mermaid syntax (`.mmd`).
- Data types follow Python naming conventions (`str`, `bool`, etc.).
- Strict adherence to case sensitivity and system specifications.
